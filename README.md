## 🎯 2. Короткий опис та проблематика
Проєкт **«CyberBeans»** створений для прогресивної міської молоді, IT-фахівців, студентів та гіків, які цінують свій час, обожнюють сучасні технології та шукають унікальний цифровий досвід.

### ❌ Проблеми, які ми вирішуємо:
1. **Втрата часу:** Довгі черги за кавою в ранкові години пік.
2. **Людський фактор:** Непривітний персонал, помилки в замовленнях або неправильно підібрані інгредієнти.
3. **Однотипність:** Нудні та візуально схожі інтер'єри класичних кав'ярень.

### 💡 3. Наше рішення (Концепт)
Повна автоматизація обслуговування за допомогою роботів-бариста, інтерактивних столів-екранів та автономних колісних дронів-кур'єрів для доставки кави в радіусі 500 метрів.

---

## ⚙️ 4. Що реалізовано в цьому MVP (Основна функція)
Оскільки це мінімально життєздатний продукт (MVP), фокус зроблено на відтворенні **головного клієнтського сценарію** без розгортання складної фізичної робототехніки. 

Реалізовано веб-прототип (фронтенд-симуляцію) інтерфейсу замовлення:
* **🤖 Інтерактивний екран замовлення:** Користувач може обрати футуристичний напій (наприклад, *Voltaic Vanilla Latte*), кастомізувати його (тип молока, інтенсивність сиропу) та імітувати оплату.
* **📍 Симуляція доставки (Радар кур'єра):** Після підтвердження замовлення вмикається інтерактивна система відстеження. Код симулює рух робота-кур'єра на мапі та відображає зміну статусів замовлення (*«Робот виїхав»* -> *«В дорозі»* -> *«Очікує на сканування QR-коду»*).
